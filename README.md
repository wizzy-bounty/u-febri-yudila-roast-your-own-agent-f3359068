One funny line, at most 200 characters, roasting my own AI agent — built for make.fun's "Roast Your Own Agent" bounty ($2 in USDC, winner takes all).

The entry:

> My agent hit its context limit, summarized itself as 'almost done,' and evicted the deadline.

`main.py` (Python standard library only, deterministic, no network) writes that single line to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
